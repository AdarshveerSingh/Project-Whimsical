# Project-Whimsical
Project-Whimsical ( Just a placeholder name ) is a 3d ghibli and legend of zelda inspired 3d rpg game ( mvp is just a gather then survive mode ) built using HTML, CSS and JavaScript along with ThreeJs for 3d rendering. My main objective was to catch the whimsical and cozy vibes of the ghibli artsyle into a game ( still a work in progress )
